Sabaq quyidagi uchinchi tomon materiallaridan foydalanadi.

## Pretendard (shrift)

| | |
|---|---|
| Muallif | Kil Hyung-jin |
| Manba | https://github.com/orioncactus/pretendard |
| Versiya | 1.3.9 (npm: `pretendard`) |
| Litsenziya | SIL Open Font License 1.1 (OFL-1.1) |
| Litsenziya matni | [docs/licenses/Pretendard-OFL-1.1.txt](docs/licenses/Pretendard-OFL-1.1.txt) |
| Reserved Font Name | "Pretendard" |

**Qanday ishlatilmoqda:** muallif tayyorlagan rasmiy `dynamic-subset` web
fayllari (`pretendard/dist/web/variable/`) o‘zgartirilmasdan ulangan va
sayt bilan birga tarqatiladi.

**OFL 1.1 bo‘yicha asosiy shartlar:**

- Shriftni tijoriy loyihalarda ham bepul ishlatish, saytga joylash va
  dasturiy ta’minot bilan birga tarqatish mumkin.
- Shrift fayllarini **alohida sotish** mumkin emas.
- Tarqatishda copyright va litsenziya matni saqlanishi kerak. Bu talab shu
  fayl va `docs/licenses/` orqali bajariladi; CSS fayl sarlavhasidagi
  copyright ham build natijasida saqlanadi.
- Shrift o‘zgartirilsa (masalan, o‘zimiz subset yaratsak), o‘zgartirilgan
  versiya **"Pretendard" nomi bilan atalmasligi** kerak (Reserved Font Name).
  Shu sababli biz faqat muallifning rasmiy fayllaridan foydalanamiz.
- Litsenziya faqat shrift fayllariga tegishli; Sabaq'ning o‘z kodi va
  kontentiga ta’sir qilmaydi.

**Belgilar qamrovi (dynamic subset):** lotin asosiy belgilari, `‘` (U+2018),
`’` (U+2019), `ʼ` (U+02BC) va Hangul to‘liq qamrab olingan. `ʻ` (U+02BB) va
kirill yozuvi subset'ga kirmaydi — bunday belgilar tizim shriftida
ko‘rsatiladi. Shuning uchun matnlarda oʻ/gʻ uchun `‘` (U+2018) ishlatiladi
(qarang: `docs/design-system.md`).
